# Portfolio d’Aymane Ait Ouhammou

Site personnel statique en français, publié gratuitement avec GitHub Pages à l’adresse [https://aymanelok.github.io](https://aymanelok.github.io). Aucun serveur ni dépendance de compilation n’est nécessaire.

## Mise en ligne avec GitHub Pages

Le dépôt `Aymanelok.github.io` publie la branche `main` depuis le dossier `/ (root)` avec GitHub Pages.

Le CV téléchargeable se trouve dans `assets/`. Il s’agit uniquement de la page CV du PDF source, sans la lettre de motivation.

## Personnalisation

Les projets et coordonnées sont dans `index.html`; les styles sont dans `styles.css` et les filtres/menu dans `script.js`.
