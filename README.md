# Portfolio d’Aymane Ait Ouhammou

Site personnel statique en français, prêt à être hébergé gratuitement avec GitHub Pages. Aucun serveur ni dépendance de compilation n’est nécessaire.

## Mise en ligne avec GitHub Pages

1. Créer un dépôt public GitHub nommé `Aymanelok.github.io` (ou choisir un autre nom).
2. Ajouter à ce dépôt les fichiers de ce dossier, en gardant `index.html` à la racine.
3. Dans **Settings → Pages**, sélectionner **Deploy from a branch**, choisir `main` et le dossier `/ (root)`, puis enregistrer.
4. Le portfolio sera disponible à `https://Aymanelok.github.io/` pour ce nom de dépôt, ou à l’adresse affichée dans les réglages Pages.

Le CV téléchargeable se trouve dans `assets/`. Il s’agit uniquement de la page CV du PDF source, sans la lettre de motivation.

## Personnalisation

Les projets et coordonnées sont dans `index.html`; les styles sont dans `styles.css` et les filtres/menu dans `script.js`.
